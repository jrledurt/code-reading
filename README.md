# code-reading

A curriculum and session log for learning to **read** code rather than write it.

The files here are the state. Any AI tool that can reach this repo can pick up
where the last session left off, regardless of which tool ran it.

## Files

- **`instructions.md`** — the tutoring contract. Load this at the start of every
  session, in any tool.
- **`curriculum.md`** — ten stages, easiest to hardest, each with measurable exit
  criteria.
- **`progress.md`** — current stage, session history, recurring misses. Updated at
  the end of each session.

## Starting a session

New chat. Say:

> Read instructions.md, curriculum.md and progress.md from jrledurt/code-reading.
> Ready to start.

If the tool has no GitHub access, paste the raw file contents instead.

## Ending a session

> Done for today. Update progress.md and commit it.
